# Tech Era

A Fabric mod for Minecraft 26.3. Start in a timber hill fort around 1000 AD and build civilisation
through five eras.

- **Website and download:** https://liamdapanda.github.io/TechEra/
- **Guide:** [GUIDE.md](GUIDE.md)
- **Downloads:** [Releases](https://github.com/LiamDaPanda/TechEra/releases)
